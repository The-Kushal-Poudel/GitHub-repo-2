# Balanced Pastel Pass

Final color balance:
- ~70% warm neutral / off-white / charcoal
- ~20% muted powder blue + lilac
- ~10% peach / mint accents

Changes:
- Removed candy-like full-section color fills.
- Hero is mostly neutral with soft blue/lilac light.
- Tech cards are primarily paper-colored; only the featured card is pastel.
- Project cards use mostly neutral surfaces with a few muted pastel cards.
- Career is a charcoal contrast section.
- Blog and contact are neutral editorial canvases.
- Footer waves use desaturated pastel layers.
- Three.js material/light saturation and opacity were reduced.
- Ambient animations were slowed slightly.

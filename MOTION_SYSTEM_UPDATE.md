# Scroll Motion System

Added a site-wide reveal system using IntersectionObserver.

Animated on entry:
- About headings, copy, portrait and principle blocks
- Tech Stack heading and every stack card
- Project heading and every project poster card
- Career heading and each timeline row
- Blog heading, featured article and every blog card
- Contact heading, each input area, message area, social rail and CTA

Additional motion:
- Project fan keeps its existing float animation after reveal
- Decorative cursive/ghost typography uses subtle scroll parallax
- Career separators draw in as rows appear
- Footer content has a small view-entry transition on supporting browsers
- Reduced-motion preferences are respected

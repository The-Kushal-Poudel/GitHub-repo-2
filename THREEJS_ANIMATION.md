# Three.js animation revision

- Added `three` and `@react-three/fiber`.
- Full-screen Hero now has a procedural crystalline 3D system, orbital lines and a light particle field.
- Motion reacts gently to pointer position and page scroll.
- Existing portrait, copy, buttons, project peek and content remain unchanged.
- Mobile reduces the 3D layer opacity.
- `prefers-reduced-motion` keeps the scene mostly static and disables CSS float animations.

Run `npm install` before `npm run dev` so the new dependencies are installed.
